# Security Policy

A clipboard manager sees a lot of private data, so security reports are taken seriously.

## Supported versions

Only the latest release of KlipLoft Mini, and the `main` branch, get security fixes.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/ronier83/KlipLoftMini/security/advisories/new)
instead.

Include what you found, how to reproduce it, and what an attacker could do with it. Don't include real
clipboard contents; use made-up data.

You'll get a reply within a few days. Once a fix ships, you'll be credited in the release notes if you'd like.
